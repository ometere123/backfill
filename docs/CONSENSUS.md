# Consensus and evidence

Claim evaluation uses `gl.vm.run_nondet_unsafe`. The leader independently fetches the repository, primary contribution and secondary evidence URLs and returns bounded structured fields. The validator independently repeats the fetch/classification boundary and rejects malformed results. Deterministic gates require confirmed attribution, pre-cutoff completion and scope match before a weight can be non-zero. Foundational impact requires two evidence paths.

Inconclusive or unavailable evidence has zero weight. The contract never converts model prose into a payout amount. The pool consumes only finalized integer weights.
